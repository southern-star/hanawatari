# 花渡市のしくみ · Architecture

ビルド工程はなく、ES モジュールだけで動きます。入口は `index.html` → `src/main.js` です。three.js 0.170 を、ブラウザでは import map（jsDelivr）から、Node では `node_modules` から読み込みます。

## 座標と約束事

- **座標系**
  - +X が東、−Z が北、y が上です。
  - 向き（yaw）は、0 が北向き、90 が西向き（`tools/shot.mjs` の表記）です。
  - モデルのローカル座標では +z が前です。進行方向 (hx, hz) に対する右は (−hz, hx) です。
- **左側通行**：way の +s 方向へ進む車線は d < 0 側にあります。way の中心線から横に d ずらした点は `(q.x − q.hz·d, q.z + q.hx·d)` です。
- **生成方法**：生成はすべて決定的です（`prng` と `mulberry32`）。同じコードからは同じ街ができます。

### 交通 · traffic.js

- **車の動き**
  - 追従は IDM（Intelligent Driver Model）です。運転手ごとに加速度、車間時間、速度の傾向が少しずつ違います。
  - 車はプレイヤーの周り 420 m で動き、最大460台です。
  - 車を出すときは、車線の長さ × 道路の格ごとの密度で配ります。プレイヤーから 95 m 以内には出しません。
- **交差点**
  - 信号に従い、黄は止まれる距離なら止まります。
  - 右折は交差点の中で対向車の切れ目を待ちます。
  - 止まれでは完全に止まってから進みます。
  - 交差点内で進路が交わる地点には、先に着いた方が進みます。この判定は双方で同じ結果になるよう対称にしているので、互いに譲り合って止まり続けることはありません。
  - 出口が詰まっているときは交差点に入りません。
- **踏切**：必ず一時停止し、遮断機が上がって渡った先に空きがあるときだけ進みます。
- **二輪**：車線の左寄りを走り、カーブでは車体を傾けます。原付は時速30 kmまでで、大きな信号交差点では右折しません。
- **人への譲り合い**
  - `pedAhead` が、次の要素とその先の横断ゾーンを見て、人が渡っていれば手前で止まります。
  - `streetPeds` は歩道のない路地用で、道の端を歩く人がいれば徐行するか後ろにつきます。
- **描画**：近くの車の運転手と、二輪の乗り手を人として描きます。
- **行き先と停車**：`v.plan`（順にたどる link）を持つ車は、`timeTo` の表（所要時間。信号や一時停止での待ち、生活道路の遅さ、行き止まりでの転回を見込む）で最も早い道を選びます。`v.stops`（車線上の停車位置）を持つ車はそこで止まり、待ち時間と `ready()` の条件を満たすと発車します。駅のバスとタクシーはこの2つで動きます。
- **専用車線**：駅前広場の車線（`private`）には、行き先を持つ駅の車しか入りません。

### 車体 · vehicles/models.js

- **車体の構造**：モデル座標の原点は前後の車軸の中点で、+x が車の左側です。
  - 車体は、断面（station）を前から後ろへつないだ滑らかな殻（`shell`）です。
  - ホイールアーチは殻を切り欠いて作り、奥にタイヤハウスを付けています。
  - 前面は上側を後ろへ寝かせています（rake）。
- **部品の分け方**：次の4つを、それぞれインスタンス描画します。
  - paint：車体色で塗る部分
  - fixed：レンズ、トリム、車内
  - glass：透けるガラス
  - lamps：ランプ。シェーダーでブレーキとウインカーを点灯させる
- **共有部品**：ホイール（3種）とナンバープレートは、全車で1つのメッシュを共有します。ナンバーは絵の束から1枚を選んで使います。

### 歩行者 · pedestrians.js と people/

- **体**：頂点ごとに骨の番号（bone）、色の枠（slot）、付け外しできる部品（part）の番号を持ちます。関節は頂点シェーダーで回します。
  - ポーズは、歩く、立つ（スマホ、手を組む、飲む、しゃべる）、自転車、バイクと車の運転、座るです。
  - 同じポーズの計算を、色のパス、輪郭線用の事前パス（`pipeline.addCustomND` とレイヤー `LAYER_CUSTOM_ND`）、影のパス（`customDepthMaterial`）で使います。
  - 近景用と遠景用の2段階の細かさを、カメラからの距離（42 m）で切り替えます。
- **歩き方**：左側通行で歩き、遅い人を追い越し、向かいから来た人とすれ違い、プレイヤーを避けます。
  - 横断歩道では歩行者用信号の青を待ち、点滅では渡り始めません。
  - 信号のない横断は車の途切れを待ち、踏切では遮断機を待ちます。
  - グループは同じ道を選び、歩く速さを揃えます。
- **車とのつながり**：`linkZones` が、横断ゾーンを横切る車線と交差点内の経路を求め、その要素に `pedX` として持たせます。車はこれを見て人に譲ります。
- **乗り場の列**：`actor` は歩行網の外で直接動かす人です。ロータリーはこれで乗り場の列、乗車、降車を演じ、降りた人は `release` で歩行網に戻します。
- **駅と横丁**
  - 駅には追加の経路（自由通路、改札、広場、デッキと階段、西口）があります。改札は人が出入りする場所です。
  - 横丁の常連（立ち飲み、ビールケースに腰かける人）は、決まった場所から動きません。

## src/core — 描画の基盤（桜ヶ丘駅から引き継いだもの）

`renderer.js` は次の順に描きます。
1. 法線と深度を描く事前パス（輪郭線の元）
2. MSAA 付きの色パス
3. ブルーム
4. 合成（輪郭線、色の調整、光漏れ、周辺減光）

そのほか、`materials.js`（トゥーン、ガラス、発光）、`sky.js`、`player.js`、`physics.js`、`audio.js`（WebAudio による音の合成）があります。

## デバッグ用のフック

ブラウザのコンソールから次のフックを使えます。
- `window.__traffic`：車と二輪。`freeze()`、`addParked(…)`、`stats()` を持つ
- `window.__peds`：歩行者。`freeze()`、`addStatic(…)`、`stats()` を持つ
- `window.__rotary`：ロータリー。`stats()` で呼び込んだ台数、乗り降りした人数、乗り場の列を返す
- `window.__step(dt, n)`：シミュレーションを進める
- `window.__sim(t)`：指定の時刻まで一気に進める
- `window.__bench(n)`：描画時間を測る
- `window.__setCam(…)`：カメラを動かす

`tools/shot.mjs --eval "…"` を使うと、撮影前にこれらを呼べます。
